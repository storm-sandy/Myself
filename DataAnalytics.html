Q1Data Analytics Fundamentals

What is data analytics?

Data analytics is the process of collecting, cleaning, transforming, analyzing, and interpreting data to answer questions, identify patterns, measure performance, and support decisions.
Q2Data Analytics Fundamentals

Data analytics vs data science?

Analytics focuses strongly on understanding data, reporting, KPIs, trends, and business decisions. Data science is broader and can include advanced statistics, machine learning, experimentation, and predictive modeling.
Q3Data Analytics Fundamentals

Descriptive vs diagnostic analytics?

Descriptive analytics explains what happened. Diagnostic analytics investigates why it happened using comparisons, segmentation, correlations, drill-downs, and root-cause analysis.
Q4Data Analytics Fundamentals

Predictive vs prescriptive analytics?

Predictive analytics estimates future outcomes. Prescriptive analytics recommends actions based on predictions, constraints, objectives, or simulations.
Q5Data Analytics Fundamentals

What is a KPI?

A Key Performance Indicator is a measurable value used to evaluate progress toward a business objective, such as conversion rate, revenue growth, retention, or average order value.
Q6Data Analytics Fundamentals

What is a metric?

A metric is a measurable quantity. A KPI is a metric selected because it is particularly important for a business objective.
Q7Data Analytics Fundamentals

What is data quality?

Data quality describes whether data is accurate, complete, consistent, timely, valid, unique, and fit for its intended purpose.
Q8Data Analytics Fundamentals

What is data cleaning?

Data cleaning identifies and corrects or handles issues such as missing values, duplicates, invalid formats, inconsistent categories, outliers, and erroneous records.
Q9Data Analytics Fundamentals

What is exploratory data analysis?

EDA is the systematic exploration of distributions, relationships, missingness, outliers, and patterns using summaries and visualizations before formal modeling or decision-making.
Q10Data Analytics Fundamentals

What is a dimension?

A dimension is a descriptive business attribute used to slice or group measures, such as product, customer, region, date, or department.
Q11Data Analytics Fundamentals

What is a measure?

A measure is a quantitative value that can usually be aggregated, such as sales, units, cost, profit, or transaction count.
Q12Data Analytics Fundamentals

What is granularity?

Granularity describes the level of detail represented by each row, such as one row per transaction, customer, product-day, or monthly account.
Q13Data Analytics Fundamentals

Why is granularity important?

Incorrect granularity can cause double counting, incorrect joins, and misleading KPIs. Analysts should establish the row grain before calculations.
Q14Data Analytics Fundamentals

What is data lineage?

Data lineage describes where data originated, how it was transformed, and where it is consumed. It supports governance, troubleshooting, and auditability.
Q15Data Analytics Fundamentals

What is a data dictionary?

A data dictionary documents fields, definitions, data types, business meaning, valid values, ownership, and sometimes lineage and quality rules.
Q16Data Analytics Fundamentals

What is an outlier?

An outlier is an observation unusually distant from the typical distribution. It may be a legitimate event, measurement error, fraud, or a data-processing issue.
Q17Data Analytics Fundamentals

How do you handle outliers?

First investigate their cause. Depending on the business context, retain them, cap/winsorize them, transform the data, segment them, or exclude confirmed errors. Never remove them automatically.
Q18Data Analytics Fundamentals

Correlation vs causation?

Correlation means variables move together statistically. Causation means a change in one variable produces a change in another. Correlation alone does not establish causality.
Q19Data Analytics Fundamentals

What is a cohort?

A cohort is a group sharing a common starting characteristic or date, such as customers acquired in the same month, used for retention and behavioral analysis.
Q20Data Analytics Fundamentals

What is segmentation?

Segmentation divides data into meaningful groups, such as customer type, geography, tenure, product, risk band, or behavior.
Q21SQL for Analytics

Why is SQL important for analysts?

SQL is a primary tool for retrieving, joining, aggregating, validating, and transforming structured data in relational warehouses and databases.
Q22SQL for Analytics

INNER JOIN vs LEFT JOIN?

INNER JOIN returns matching rows from both tables. LEFT JOIN preserves every row from the left table and adds matching right-side data where available.
Q23SQL for Analytics

WHERE vs HAVING?

WHERE filters individual rows before aggregation. HAVING filters grouped results after GROUP BY.
Q24SQL for Analytics

GROUP BY purpose?

GROUP BY creates groups so aggregate functions such as SUM, COUNT, AVG, MIN, and MAX can be calculated per group.
Q25SQL for Analytics

COUNT(*) vs COUNT(column)?

COUNT(*) counts rows. COUNT(column) counts non-NULL values in that column.
Q26SQL for Analytics

UNION vs UNION ALL?

UNION removes duplicate rows between result sets. UNION ALL retains duplicates and is generally faster when duplicate elimination is unnecessary.
Q27SQL for Analytics

What is a CTE?

A Common Table Expression uses WITH to define a named query block, improving readability and enabling multi-step SQL transformations.
Q28SQL for Analytics

What is a subquery?

A subquery is a query nested inside another query. It can be used for filtering, derived tables, scalar expressions, and correlated logic.
Q29SQL for Analytics

What is a window function?

A window function calculates across related rows without collapsing them into one row per group. Examples include ROW_NUMBER, RANK, LAG, LEAD, and SUM OVER.
Q30SQL for Analytics

ROW_NUMBER vs RANK?

ROW_NUMBER assigns a unique sequence. RANK assigns equal values the same rank and leaves gaps after ties.
Q31SQL for Analytics

What is LAG?

LAG returns a value from a previous row within an ordered window, useful for period-over-period comparisons.
Q32SQL for Analytics

What is LEAD?

LEAD returns a value from a following row within an ordered window, useful for next-event or future-period comparisons.
Q33SQL for Analytics

How do you calculate month-over-month growth?

Aggregate the metric by month, use LAG to obtain the prior month's value, then calculate (current - previous) / previous while handling zero and NULL cases.
Q34SQL for Analytics

How do you find duplicates?

GROUP BY the business key and use HAVING COUNT(*) > 1. To retrieve duplicate rows, use ROW_NUMBER or join the duplicate-key result back to the source.
Q35SQL for Analytics

How do you get the top 3 products per category?

Use ROW_NUMBER or DENSE_RANK partitioned by category and ordered by the relevant measure descending, then filter the rank.
Q36SQL for Analytics

What is a CASE expression?

CASE implements conditional logic inside SQL expressions, useful for classifications, flags, buckets, and conditional calculations.
Q37SQL for Analytics

What is COALESCE?

COALESCE returns the first non-NULL expression from its arguments and is commonly used for default values.
Q38SQL for Analytics

What is NULL?

NULL represents an unknown or missing value. It is not equal to zero or an empty string conceptually, and comparisons require IS NULL/IS NOT NULL.
Q39SQL for Analytics

What is a self join?

A self join joins a table to itself using aliases, such as mapping employees to managers.
Q40SQL for Analytics

How do you optimize an analytical SQL query?

Filter early where appropriate, select only needed columns, avoid accidental many-to-many joins, use correct join keys, pre-aggregate when useful, inspect execution plans, and leverage warehouse partitioning/clustering.
Q41Python & Pandas

Why use Python for analytics?

Python has a rich ecosystem for data manipulation, statistics, visualization, automation, APIs, and machine learning. Pandas and NumPy are especially common.
Q42Python & Pandas

What is Pandas?

Pandas is a Python library providing Series and DataFrame structures and tools for data cleaning, transformation, aggregation, time-series analysis, and file I/O.
Q43Python & Pandas

Series vs DataFrame?

A Series is one-dimensional labeled data. A DataFrame is a two-dimensional labeled table made from rows and columns.
Q44Python & Pandas

How do you read a CSV?

Use pandas.read_csv(path). For production workflows, specify relevant data types, parsing options, encoding, and missing-value behavior when appropriate.
Q45Python & Pandas

How do you inspect a DataFrame?

Use head(), tail(), shape, columns, dtypes, info(), describe(), isna().sum(), and value_counts() for relevant columns.
Q46Python & Pandas

How do you handle missing values in Pandas?

Use isna()/notna() to inspect, then dropna(), fillna(), forward/backward fill, or model/business-rule-based imputation depending on the data.
Q47Python & Pandas

How do you remove duplicates?

Use drop_duplicates(), optionally specifying a subset and deterministic keep behavior.
Q48Python & Pandas

merge vs concat?

merge performs relational-style joins based on keys. concat combines objects along rows or columns.
Q49Python & Pandas

loc vs iloc?

loc selects using labels and boolean conditions. iloc selects by integer positions.
Q50Python & Pandas

How do you group data?

Use groupby() followed by aggregation, transformation, filtering, or apply where appropriate.
Q51Python & Pandas

apply vs vectorization?

Vectorized operations generally use optimized array operations and are preferred for performance. apply is flexible but can be slower when used row-by-row.
Q52Python & Pandas

How do you create a calculated column?

Assign a Series expression, for example df['profit'] = df['revenue'] - df['cost'].
Q53Python & Pandas

How do you detect outliers in Python?

Common approaches include IQR rules, z-scores, robust statistics, visualizations, and domain thresholds. The correct method depends on distribution and business context.
Q54Python & Pandas

What is NumPy?

NumPy provides efficient multidimensional arrays and numerical operations and is a foundation for many Python data-analysis libraries.
Q55Python & Pandas

How do you work with dates in Pandas?

Use to_datetime(), datetime properties such as dt.year/dt.month, date offsets, resampling, and time-based indexing where appropriate.
Q56Python & Pandas

How do you optimize Pandas for large data?

Select only needed columns, use appropriate dtypes, process chunks, avoid unnecessary copies, use vectorized operations, and consider a database, Polars, Dask, or Spark when data exceeds practical memory limits.
Q57Python & Pandas

What is a pivot table in Pandas?

pivot_table() creates grouped summaries with configurable index, columns, values, and aggregation functions.
Q58Python & Pandas

How do you export a DataFrame?

Use to_csv(), to_excel(), to_parquet(), or other appropriate writers depending on the target and analytical workload.
Q59Python & Pandas

What is method chaining?

It is writing sequential DataFrame transformations as a readable chain, often using assign, query, groupby, merge, and related methods.
Q60Python & Pandas

How do you validate a Pandas transformation?

Compare row counts, key uniqueness, null counts, distributions, totals, sample records, and expected business rules before and after transformation.
Q61Statistics & Probability

Mean vs median?

Mean is the arithmetic average and is sensitive to extreme values. Median is the middle ordered value and is more robust to skew and outliers.
Q62Statistics & Probability

Mode?

Mode is the most frequently occurring value. It can be useful for categorical data.
Q63Statistics & Probability

Variance vs standard deviation?

Variance is the average squared deviation from the mean. Standard deviation is its square root and is expressed in the original units.
Q64Statistics & Probability

What is percentile?

A percentile indicates the value below which a specified percentage of observations fall, such as the 90th percentile.
Q65Statistics & Probability

What is a confidence interval?

A confidence interval gives a range produced by a statistical procedure intended to capture an unknown population parameter with a specified long-run coverage level.
Q66Statistics & Probability

What is a hypothesis test?

It evaluates evidence against a null hypothesis using a test statistic, sampling distribution, and significance criterion.
Q67Statistics & Probability

What is a p-value?

A p-value measures how unusual data would be under the null hypothesis according to the specified test. It is not the probability that the null hypothesis is true.
Q68Statistics & Probability

What is statistical significance?

It means the observed result would be relatively unlikely under the null model at the chosen significance threshold. Practical importance must also be evaluated.
Q69Statistics & Probability

Type I vs Type II error?

Type I error is rejecting a true null hypothesis. Type II error is failing to reject a false null hypothesis.
Q70Statistics & Probability

What is statistical power?

Power is the probability of detecting a specified effect when that effect truly exists under the assumed conditions.
Q71Statistics & Probability

What is sampling bias?

Sampling bias occurs when the sampling process systematically produces a sample that does not represent the target population.
Q72Statistics & Probability

What is selection bias?

Selection bias occurs when inclusion in the analyzed sample is related to characteristics affecting the outcome or exposure, producing systematic distortion.
Q73Statistics & Probability

What is normal distribution?

A symmetric bell-shaped distribution characterized by its mean and standard deviation. Many statistical methods use it as an assumption or approximation.
Q74Statistics & Probability

What is skewness?

Skewness describes asymmetry in a distribution. Positive skew typically has a longer right tail; negative skew has a longer left tail.
Q75Statistics & Probability

What is covariance?

Covariance measures how two variables vary together. Its magnitude depends on units, so correlation is often easier to interpret.
Q76Statistics & Probability

What is correlation?

Correlation standardizes covariance to a bounded scale, commonly -1 to +1, indicating direction and strength of linear association.
Q77Statistics & Probability

What is a confidence level?

A confidence level such as 95% describes the long-run coverage property of an interval-generating procedure, not the probability that a fixed parameter lies in one realized interval.
Q78Statistics & Probability

When use t-test?

A t-test is commonly used to compare means when assumptions and design make it appropriate, including one-sample, paired, and two-sample forms.
Q79Statistics & Probability

What is ANOVA?

Analysis of variance tests whether there is evidence that means differ across multiple groups, with follow-up comparisons used when appropriate.
Q80Statistics & Probability

What is a chi-square test?

It is commonly used for categorical data to test independence or goodness of fit under suitable assumptions.
Q81Excel & Spreadsheet Analytics

Why is Excel important for analysts?

Excel remains widely used for ad hoc analysis, reconciliation, reporting, financial models, data cleaning, and stakeholder collaboration.
Q82Excel & Spreadsheet Analytics

VLOOKUP vs XLOOKUP?

XLOOKUP is more flexible and can search in either direction with explicit match and fallback options. VLOOKUP traditionally searches the first column of a range and returns a column to its right.
Q83Excel & Spreadsheet Analytics

What is INDEX-MATCH?

INDEX returns a value at a specified position, while MATCH finds a position. Together they provide flexible lookup behavior and are useful in environments without XLOOKUP.
Q84Excel & Spreadsheet Analytics

What is a PivotTable?

A PivotTable summarizes large tabular data by grouping fields and calculating measures such as sums, counts, and averages.
Q85Excel & Spreadsheet Analytics

What is conditional formatting?

It applies formatting based on rules, making exceptions, thresholds, duplicates, and trends easier to identify.
Q86Excel & Spreadsheet Analytics

What are absolute references?

An absolute reference such as $A$1 remains fixed when a formula is copied.
Q87Excel & Spreadsheet Analytics

What is Power Query?

Power Query is a data-import and transformation tool used to connect to sources, clean data, combine files, and create repeatable transformation steps.
Q88Excel & Spreadsheet Analytics

How do you remove duplicates in Excel?

Use the Remove Duplicates feature or formulas/functions such as UNIQUE where available, depending on whether you need a static result or dynamic output.
Q89Excel & Spreadsheet Analytics

How do you create a dynamic report?

Use structured tables, PivotTables, Power Query, formulas, validation controls, and charts with clear refresh and source-data logic.
Q90Excel & Spreadsheet Analytics

What Excel functions are useful for analytics?

SUMIFS, COUNTIFS, AVERAGEIFS, IF, IFERROR, XLOOKUP, INDEX/MATCH, TEXT functions, date functions, UNIQUE, FILTER, SORT, and dynamic-array functions are common.
Q91Power BI & Tableau

What is Power BI?

Power BI is a business intelligence platform for connecting data, transforming it, building semantic models, creating reports/dashboards, and sharing insights.
Q92Power BI & Tableau

What is Tableau?

Tableau is a visualization and analytics platform used to connect data, explore it interactively, and build dashboards and analytical views.
Q93Power BI & Tableau

Measure vs calculated column in Power BI?

A measure is calculated at query time according to filter context and is usually preferred for aggregations. A calculated column is stored at row level in the model and can increase model size.
Q94Power BI & Tableau

What is DAX?

DAX is the expression language used in Power BI semantic models and Analysis Services for measures, calculated columns, and tables.
Q95Power BI & Tableau

What is filter context?

Filter context is the set of filters affecting evaluation of a DAX measure, coming from visuals, slicers, relationships, and explicit filter expressions.
Q96Power BI & Tableau

What is row context?

Row context represents the current row when evaluating a calculated column or certain iterator expressions.
Q97Power BI & Tableau

What is a star schema?

A star schema has a central fact table connected to descriptive dimension tables. It is a common design for analytical models.
Q98Power BI & Tableau

Fact vs dimension table?

Fact tables contain measurable business events or snapshots. Dimension tables contain descriptive attributes used to filter and group facts.
Q99Power BI & Tableau

What is a dashboard?

A dashboard is a curated visual interface presenting important metrics, trends, exceptions, and interactive analysis for a target audience.
Q100Power BI & Tableau

What makes a good dashboard?

Clear purpose, appropriate visuals, consistent definitions, limited clutter, useful filters, visible KPI context, performance, accessibility, and actionable insights.
Q101Power BI & Tableau

What is drill-through?

Drill-through lets users navigate from a summary view to a detailed page filtered to the selected context.
Q102Power BI & Tableau

What is row-level security?

RLS restricts which rows a user can access based on identity or role rules in supported BI platforms.
Q103Power BI & Tableau

Import vs DirectQuery in Power BI?

Import loads data into the model for fast in-memory analysis. DirectQuery queries the source at interaction time, reducing imported storage but adding source-performance and modeling considerations.
Q104Power BI & Tableau

What is dashboard performance tuning?

Reduce unnecessary visuals, optimize the semantic model, use a star schema, minimize high-cardinality fields where practical, optimize source queries, and monitor query/model performance.
Q105Power BI & Tableau

What is a semantic layer?

A semantic layer provides governed business entities, relationships, measures, definitions, and access rules so consumers use consistent metrics.
Q106ETL, Warehousing & Data Engineering

What is ETL?

Extract, Transform, Load moves data from source systems, applies transformations, and loads it into a target such as a warehouse.
Q107ETL, Warehousing & Data Engineering

ETL vs ELT?

ETL transforms before loading. ELT loads raw or lightly processed data first and performs transformations within the target analytical platform.
Q108ETL, Warehousing & Data Engineering

What is a data warehouse?

A data warehouse is an analytical data store designed for integrated, historical, and query-oriented reporting and analysis.
Q109ETL, Warehousing & Data Engineering

What is a data lake?

A data lake stores large volumes of data in varied formats, often retaining raw data for flexible downstream processing.
Q110ETL, Warehousing & Data Engineering

What is a data mart?

A data mart is a subject-oriented analytical store or layer focused on a business area such as sales, finance, or marketing.
Q111ETL, Warehousing & Data Engineering

What is a fact table?

A fact table stores measurable business events or periodic/accumulating snapshots at a defined grain.
Q112ETL, Warehousing & Data Engineering

What is SCD?

Slowly Changing Dimensions are techniques for managing changes to dimension attributes over time.
Q113ETL, Warehousing & Data Engineering

Explain SCD Type 1.

Type 1 overwrites the old attribute value and does not retain historical versions.
Q114ETL, Warehousing & Data Engineering

Explain SCD Type 2.

Type 2 creates a new dimension version, typically with effective dates/current flags or version identifiers, preserving history.
Q115ETL, Warehousing & Data Engineering

What is incremental loading?

Only new or changed records are processed instead of reloading the entire dataset. Watermarks, timestamps, change data capture, or keys can support it.
Q116ETL, Warehousing & Data Engineering

What is CDC?

Change Data Capture identifies inserts, updates, and deletes from a source so downstream systems can process changes incrementally.
Q117ETL, Warehousing & Data Engineering

What is data validation?

Checks include row counts, null constraints, uniqueness, referential integrity, valid ranges, reconciliation totals, schema checks, and business rules.
Q118ETL, Warehousing & Data Engineering

What is an audit table?

An audit/control table records pipeline runs, start/end times, source/target counts, status, errors, batch identifiers, and other operational metadata.
Q119ETL, Warehousing & Data Engineering

What is a data pipeline?

A data pipeline is an automated sequence that moves and transforms data between systems with scheduling, monitoring, error handling, and operational controls.
Q120ETL, Warehousing & Data Engineering

What is orchestration?

Orchestration coordinates task dependencies, scheduling, retries, parameters, alerts, and execution state across a data workflow.
Q121Business & Product Analytics

What is conversion rate?

Conversion rate is the proportion of eligible users or events that complete a defined target action. The denominator must be explicitly defined.
Q122Business & Product Analytics

What is retention rate?

Retention measures the proportion of a cohort that remains active or retained after a defined period.
Q123Business & Product Analytics

What is churn?

Churn measures customers, users, subscriptions, or revenue lost during a specified period. The exact denominator and event definition must be stated.
Q124Business & Product Analytics

What is customer lifetime value?

CLV estimates the economic value associated with a customer over the relationship. The calculation depends on margin, retention, purchase behavior, discounting, and business assumptions.
Q125Business & Product Analytics

What is CAC?

Customer Acquisition Cost measures acquisition spend relative to newly acquired customers over a defined period.
Q126Business & Product Analytics

What is average order value?

AOV is typically revenue divided by number of orders over a defined period, with clear treatment of refunds, taxes, shipping, and discounts.
Q127Business & Product Analytics

What is funnel analysis?

Funnel analysis measures progression and drop-off through ordered stages such as visit, signup, activation, purchase, and repeat use.
Q128Business & Product Analytics

What is cohort analysis?

Cohort analysis compares groups that started at similar times or under similar conditions to understand retention, revenue, or behavior over their lifecycle.
Q129Business & Product Analytics

What is A/B testing?

A/B testing randomly assigns eligible users to variants and compares predefined outcomes while controlling exposure and analyzing statistical uncertainty.
Q130Business & Product Analytics

What makes an experiment trustworthy?

Clear hypothesis, randomization, consistent treatment, adequate sample size/power, predefined metrics, clean exposure data, guardrails, and appropriate statistical analysis.
Q131Business & Product Analytics

What is a north-star metric?

A north-star metric is a high-level measure intended to capture durable customer/business value and align teams around a strategic objective.
Q132Business & Product Analytics

What is root-cause analysis?

It is a structured investigation to identify underlying drivers of an observed issue rather than stopping at symptoms.
Q133Business & Product Analytics

How do you prioritize metrics?

Tie metrics to business objectives, distinguish leading from lagging indicators, define ownership, and avoid metric overload.
Q134Business & Product Analytics

How do you communicate bad results?

State the result clearly, quantify impact and uncertainty, explain likely drivers, distinguish facts from hypotheses, and recommend next investigative or corrective actions.
Q135Business & Product Analytics

How do you translate a business question into analysis?

Clarify the decision, define population/time window/unit of analysis, specify metrics and dimensions, identify data sources, validate assumptions, analyze, and present an actionable conclusion.
Q136Advanced Analytics & Case Studies

How would you investigate a 20% sales drop?

Validate the metric and data first, then segment by time, geography, product, channel, customer, price, volume, and operational factors. Compare against baseline and investigate the largest contribution to the change.
Q137Advanced Analytics & Case Studies

A dashboard revenue number is different from finance. What do you do?

Reconcile definitions, grain, time zone, currency, refunds, taxes, status filters, late-arriving data, joins, and source refresh times. Trace both calculations to source records.
Q138Advanced Analytics & Case Studies

A KPI increased but business performance did not. Why?

Check denominator changes, mix effects, tracking changes, data quality, seasonality, metric definition, and whether the KPI is actually aligned with the desired business outcome.
Q139Advanced Analytics & Case Studies

How do you analyze customer churn?

Define churn precisely, create cohorts, examine churn timing, segment by tenure/product/channel, compare retained vs churned behavior, identify leading signals, and validate findings against business context.
Q140Advanced Analytics & Case Studies

How would you analyze declining conversion?

Map the funnel, calculate stage-level conversion and volume, compare periods/segments, check traffic mix and instrumentation, and identify the stage contributing most to the decline.
Q141Advanced Analytics & Case Studies

How do you evaluate a marketing campaign?

Define incremental objectives, compare exposed/control or suitable baseline groups, analyze acquisition, conversion, revenue/margin, CAC, retention, and guardrails while accounting for attribution limitations.
Q142Advanced Analytics & Case Studies

How do you detect fraud/anomalies?

Create behavioral and rule-based indicators, compare distributions and peer groups, examine velocity and unusual combinations, prioritize high-risk cases, and validate against labeled outcomes where available.
Q143Advanced Analytics & Case Studies

What is Simpson's paradox?

An association can appear in aggregated data but reverse or disappear after splitting by a confounding/grouping variable. Always inspect important segments before drawing conclusions.
Q144Advanced Analytics & Case Studies

What is survivorship bias?

It occurs when analysis includes only entities that survived or remained visible, ignoring those that failed or disappeared, leading to overly optimistic conclusions.
Q145Advanced Analytics & Case Studies

What is confounding?

A confounder is a variable associated with both the explanatory variable and outcome that can distort the observed relationship.
Q146Advanced Analytics & Case Studies

What is selection bias in product analytics?

It can occur when analyzed users differ systematically from the broader target population, such as only analyzing active users.
Q147Advanced Analytics & Case Studies

How do you choose between mean and median for business reporting?

Use the metric distribution and decision context. Median is often better for highly skewed values such as transaction amounts or response times, while mean is useful when total-average behavior matters.
Q148Advanced Analytics & Case Studies

What is a leading indicator?

A leading indicator tends to change before the outcome of interest and can provide early signals. A lagging indicator measures an outcome after it occurs.
Q149Advanced Analytics & Case Studies

What is sensitivity analysis?

Sensitivity analysis tests how conclusions or outputs change when assumptions or input values vary.
Q150Advanced Analytics & Case Studies

What is scenario analysis?

Scenario analysis evaluates outcomes under defined alternative conditions, such as optimistic, base, and pessimistic assumptions.
Q151Advanced Analytics & Case Studies

How do you validate a surprising analytical finding?

Reproduce it independently, check source data and definitions, inspect segment-level behavior, test alternative calculations, investigate data changes, and seek domain validation.
Q152Advanced Analytics & Case Studies

How do you handle ambiguous requirements?

Ask focused questions about the decision, definitions, scope, grain, time period, users, and acceptance criteria; document assumptions before proceeding.
Q153Advanced Analytics & Case Studies

How do you estimate effort for an analytics request?

Break it into data access, extraction, cleaning, modeling, analysis, validation, visualization, stakeholder review, and deployment/refresh requirements.
Q154Advanced Analytics & Case Studies

How do you present an analysis to executives?

Lead with the decision-relevant conclusion, quantify business impact, show a small number of supporting visuals, explain key drivers and uncertainty, and recommend actions.
Q155Advanced Analytics & Case Studies

What should an analytics project README contain?

Business objective, data sources, definitions, assumptions, transformation logic, methodology, validation checks, refresh process, limitations, ownership, and usage instructions.

What is a metric tree?

What is a many-to-many join problem?

It occurs when both sides contain multiple rows for the join key, multiplying records and potentially inflating aggregates. Establish grain and pre-aggregate or deduplicate when appropriate.

What is a semi-join?

A semi-join returns rows from one side when a match exists on the other side, often represented by EXISTS or a left-semi join in engines that support it.
