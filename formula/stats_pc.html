1. Factorials & Fundamental Counting Principle

Factorial definition

n! = n(n−1)(n−2)⋯3×2×1
For positive integer n.

Zero factorial

0! = 1

Recursive factorial

n! = n(n−1)!

Factorial ratio

n!/(n−r)! = n(n−1)⋯(n−r+1)

Fundamental counting principle

Total ways = m₁×m₂×⋯×mₖ
If successive choices have m₁,m₂,...,mₖ possibilities.

Sum rule

If choices are mutually exclusive:
Total ways = m+n

Useful factorial identities

(n+1)!=(n+1)n!
(n−1)!=n!/n

Factorial cancellation

n!/[n(n−1)] = (n−2)!

2. Permutations — Arrangements Where Order Matters

Main formula

n objects taken r at a time

ⁿPᵣ = n!/(n−r)!
Example: 5P2 = 5!/3! = 20.

All n distinct objects

ⁿPₙ = n!

Permutation of n objects, r=1

ⁿP₁ = n

Permutation relation

ⁿPᵣ = r! × ⁿCᵣ

Alternative permutation form

ⁿPᵣ = n(n−1)(n−2)⋯(n−r+1)

Reverse relation

ⁿPᵣ = n!/(n−r)!
ⁿPₙ₋ᵣ = n!/r!

Permutation symmetry

ⁿPᵣ / ⁿPᵣ₋₁ = n−r+1

Arrangements of distinct letters

n distinct letters → n!

Arrange r selected objects

Choose r and arrange = ⁿCᵣ × r! = ⁿPᵣ

3. Permutations With Repetition & Identical Objects

Repetition allowed

n objects/types, r positions:
Total = nʳ
Each position can independently use any of n choices.

Repeated/identical objects

Number of arrangements = n!/(p!q!r!⋯)
p,q,r,... are repetition counts.

Two identical groups

n!/(p!q!)
For AABBC: 5!/(2!2!) = 30.

Three identical groups

n!/(p!q!r!)

Multiset permutation

n!/(n₁!n₂!⋯nₖ!)
n=n₁+n₂+⋯+nₖ.

Repeated letters with restrictions

Total valid = total arrangements − invalid arrangements
Use complementary counting or inclusion-exclusion for restrictions.

4. Circular Permutations

Round table

n distinct people around a circle

(n−1)!
Rotations are considered identical.

Circular arrangement when clockwise and anticlockwise are identical

(n−1)!/2
Used for arrangements where mirror images are considered the same.

Fix one object method

Fix 1 object → arrange remaining n−1 objects:
(n−1)!

People together in a circle

Treat the group as one block, then arrange blocks circularly

Alternating circular arrangements

Arrange one group around circle, then place the other group in gaps
For n men and n women alternating: (n−1)! × n!.

5. Combinations — Selections Where Order Does Not Matter

Main formula

n objects selected r at a time

ⁿCᵣ = n!/[r!(n−r)!]
Example: 5C2 = 10.

Combination with permutation

ⁿPᵣ = ⁿCᵣ × r!

Symmetry property

ⁿCᵣ = ⁿCₙ₋ᵣ

Boundary values

ⁿC₀=1
ⁿC₁=n
ⁿCₙ=1

Second boundary value

ⁿCₙ₋₁=n

Pascal identity

ⁿCᵣ = ⁿ⁻¹Cᵣ + ⁿ⁻¹Cᵣ₋₁

Combination product identity

ⁿCᵣ × rCₖ = ⁿCₖ × ⁿ⁻ᵏCᵣ₋ₖ

Ratio identity

ⁿCᵣ / ⁿCᵣ₋₁ = (n−r+1)/r

Another ratio identity

ⁿCᵣ / ⁿCᵣ₊₁ = (r+1)/(n−r)

6. Combinations With Repetition

Selection with repetition

Number of ways = C(n+r−1,r)
Choose r objects from n types when unlimited repetition is allowed.

Equivalent form

C(n+r−1,n−1)

Stars and bars

x₁+x₂+⋯+xₙ=r, xᵢ≥0
Number = C(n+r−1,r)

Positive integer solutions

x₁+x₂+⋯+xₙ=r, xᵢ≥1
Number = C(r−1,n−1)

At least one of each

x₁+⋯+xₙ=r, xᵢ≥1
Set yᵢ=xᵢ−1 → C(r−1,n−1)

Upper-bound restrictions

Use inclusion-exclusion or generating functions
For conditions such as xᵢ≤k.
