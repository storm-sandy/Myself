1. Descriptive Statistics

Mean

x̄ = (Σxᵢ)/n

Weighted mean

x̄w = Σwᵢxᵢ / Σwᵢ

Median

Odd n: x₍(n+1)/2₎
Even n: [x₍n/2₎ + x₍n/2+1₎]/2

Range

Range = max(x) − min(x)

Population variance

σ² = Σ(xᵢ−μ)²/N

Sample variance

s² = Σ(xᵢ−x̄)²/(n−1)

Population standard deviation

σ = √[Σ(xᵢ−μ)²/N]

Sample standard deviation

s = √[Σ(xᵢ−x̄)²/(n−1)]

Coefficient of variation

CV = σ/μ × 100%

Z-score

z = (x−μ)/σ

Percentile position

Position ≈ (p/100)(n+1)
Common interpolation convention; software may use different percentile definitions.

IQR

IQR = Q₃ − Q₁

Outlier fences

Lower = Q₁−1.5IQR
Upper = Q₃+1.5IQR

2. Probability & Distributions

Basic probability

P(A)=favourable outcomes/total outcomes

Complement

P(Aᶜ)=1−P(A)

Union

P(A∪B)=P(A)+P(B)−P(A∩B)

Conditional probability

P(A|B)=P(A∩B)/P(B)

Independent events

P(A∩B)=P(A)P(B)

Bayes theorem

P(A|B)=P(B|A)P(A)/P(B)

Expected value

E[X]=ΣxP(X=x)

Variance

Var(X)=E[X²]−E[X]²

Covariance

Cov(X,Y)=E[(X−μx)(Y−μy)]

Correlation

ρ = Cov(X,Y)/(σxσy)
Binomial

Binomial PMF

P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ

Binomial mean & variance

E[X]=np
Var(X)=np(1−p)
Normal

Normal PDF

f(x)=1/(σ√2π) · exp[−(x−μ)²/(2σ²)]

Standard normal transformation

Z=(X−μ)/σ
Poisson

Poisson PMF

P(X=k)=e⁻λ λᵏ/k!

Poisson mean & variance

E[X]=λ
Var(X)=λ

3. Statistical Inference & Hypothesis Testing

Standard error of mean

SE(x̄)=σ/√n
Estimated: s/√n

Confidence interval for mean

x̄ ± z* σ/√n
For known population σ under standard assumptions.

t-statistic for one mean

t=(x̄−μ₀)/(s/√n)

Two-sample mean difference

t=(x̄₁−x̄₂)/SE(x̄₁−x̄₂)

One-proportion z test

z=(p̂−p₀)/√[p₀(1−p₀)/n]

Chi-square statistic

χ²=Σ(O−E)²/E

F-statistic

F = variance₁ / variance₂

ANOVA F ratio

F = MS_between / MS_within

p-value rule

Reject H₀ if p-value ≤ α

Type I error

P(reject H₀ | H₀ true)=α

Type II error

β=P(fail to reject H₀ | H₁ true)

Power

Power = 1−β

4. Linear Algebra

Vector addition

a+b=[a₁+b₁,...,aₙ+bₙ]

Dot product

a·b=Σaᵢbᵢ

Vector norm

||x||₂=√(Σxᵢ²)

L1 norm

||x||₁=Σ|xᵢ|

Cosine similarity

cosθ=(a·b)/(||a||||b||)

Euclidean distance

d(x,y)=√Σ(xᵢ−yᵢ)²

Manhattan distance

d(x,y)=Σ|xᵢ−yᵢ|

Matrix multiplication

(AB)ᵢⱼ=ΣₖAᵢₖBₖⱼ

Transpose

(Aᵀ)ᵢⱼ=Aⱼᵢ

Inverse of 2×2 matrix

A⁻¹=1/(ad−bc)[[d,−b],[-c,a]]

Determinant 2×2

det(A)=ad−bc

Eigenvalue equation

Av=λv

Characteristic equation

det(A−λI)=0

Trace

tr(A)=Σaᵢᵢ = Σ eigenvalues

Projection of a onto b

proj_b(a)=(a·b)/(b·b) · b

Matrix norm — Frobenius

||A||F=√(ΣᵢΣⱼaᵢⱼ²)

5. Calculus for Data Science & ML

Derivative — power rule

d(xⁿ)/dx = nxⁿ⁻¹

Product rule

(fg)'=f'g+fg'

Quotient rule

(f/g)'=(f'g−fg')/g²

Chain rule

d f(g(x))/dx=f'(g(x))g'(x)

Exponential

d(eˣ)/dx=eˣ

Logarithm

d(ln x)/dx=1/x

Sigmoid derivative

σ'(z)=σ(z)[1−σ(z)]

ReLU derivative

ReLU'(x)=1 if x>0; 0 if x<0

Gradient

∇f=[∂f/∂x₁,...,∂f/∂xₙ]ᵀ

Hessian

Hᵢⱼ=∂²f/(∂xᵢ∂xⱼ)

Gradient descent

θₜ₊₁=θₜ−η∇J(θₜ)

Gradient ascent

θₜ₊₁=θₜ+η∇J(θₜ)

First-order Taylor approximation

f(x+Δx)≈f(x)+∇f(x)ᵀΔx

Convexity condition

Hessian ⪰ 0 ⇒ convex (twice differentiable case)

6. Data Preprocessing & Feature Scaling

Min-max normalization

x'=(x−x_min)/(x_max−x_min)

Min-max to [a,b]

x'=a+(x−x_min)(b−a)/(x_max−x_min)

Standardization

z=(x−μ)/σ

Robust scaling

x'=(x−median)/IQR

Mean imputation

x_missing → mean(observed x)

Median imputation

x_missing → median(observed x)

One-hot encoding

Category k → binary vector e_k

Train-test split

N = N_train + N_test

Sampling fraction

fraction = sample size / population size

Class weight

w_c = N/(K·N_c)
Common balanced-class weighting formula.

7. Linear & Polynomial Regression

Simple linear regression

ŷ=β₀+β₁x

Multiple linear regression

ŷ=β₀+β₁x₁+⋯+β_px_p

Matrix regression

ŷ=Xβ

OLS estimate

β̂=(XᵀX)⁻¹Xᵀy
Assuming XᵀX is invertible.

Residual

eᵢ=yᵢ−ŷᵢ

SSE

SSE=Σ(yᵢ−ŷᵢ)²

MSE

MSE=(1/n)Σ(yᵢ−ŷᵢ)²

RMSE

RMSE=√MSE

MAE

MAE=(1/n)Σ|yᵢ−ŷᵢ|

R²

R²=1−SSE/SST

SST

SST=Σ(yᵢ−ȳ)²

Adjusted R²

R²_adj=1−(1−R²)(n−1)/(n−p−1)

Ridge regression

minβ ||y−Xβ||² + λ||β||²

Lasso regression

minβ ||y−Xβ||² + λ||β||₁

Elastic Net

Loss + λ₁||β||₁ + λ₂||β||²

8. Logistic Regression & Classification

Logit / linear score

z=β₀+βᵀx

Sigmoid

σ(z)=1/(1+e⁻ᶻ)

Log-odds

log[p/(1−p)] = β₀+βᵀx

Binary cross-entropy

L=−[y log p +(1−y)log(1−p)]

Dataset BCE

J=−(1/n)Σ[yᵢlog pᵢ +(1−yᵢ)log(1−pᵢ)]

Softmax

P(y=k|x)=eᶻᵏ/Σⱼeᶻʲ

Multiclass cross-entropy

L=−Σₖ yₖlog pₖ

Odds ratio

OR=e^βⱼ
For a one-unit increase in feature xⱼ, holding other variables fixed.

Naive Bayes

P(y|x₁...xₙ) ∝ P(y)∏P(xᵢ|y)

Perceptron prediction

ŷ=sign(wᵀx+b)

Hinge loss

L=max(0,1−y f(x))

Support Vector Machine objective

min ½||w||² + CΣξᵢ

9. Classification Evaluation Metrics

Accuracy

(TP+TN)/(TP+TN+FP+FN)

Precision

TP/(TP+FP)

Recall / Sensitivity

TP/(TP+FN)

Specificity

TN/(TN+FP)

False positive rate

FPR=FP/(FP+TN)=1−specificity

False negative rate

FNR=FN/(FN+TP)=1−recall

F1 score

F1=2PR/(P+R)

Balanced accuracy

(Sensitivity+Specificity)/2

Jaccard score

TP/(TP+FP+FN)

Matthews correlation coefficient

MCC=(TP·TN−FP·FN)/√[(TP+FP)(TP+FN)(TN+FP)(TN+FN)]

Log loss

−(1/n)Σ[yᵢlog pᵢ +(1−yᵢ)log(1−pᵢ)]

Mean squared error

MSE=(1/n)Σ(yᵢ−ŷᵢ)²

10. ROC, AUC & Ranking Metrics

ROC coordinates

x=FPR
y=TPR

TPR

TPR=TP/(TP+FN)

AUC

AUC = area under ROC curve

Precision-Recall curve

x=Recall
y=Precision

Top-k accuracy

Correct if true class is among top k predicted classes

Lift

Lift = response rate in selected group / overall response rate

11. Clustering & Distance Measures

K-means objective

J=ΣₖΣ_{xᵢ∈Cₖ} ||xᵢ−μₖ||²

K-means centroid

μₖ=(1/|Cₖ|)Σ_{xᵢ∈Cₖ}xᵢ

Euclidean distance

d(x,y)=√Σ(xᵢ−yᵢ)²

Manhattan distance

d(x,y)=Σ|xᵢ−yᵢ|

Minkowski distance

d(x,y)=(Σ|xᵢ−yᵢ|ᵖ)¹/ᵖ

Cosine distance

d_cos=1−(x·y)/(||x||||y||)

Silhouette coefficient

s=(b−a)/max(a,b)
a = mean intra-cluster distance; b = lowest mean distance to another cluster.

DBSCAN core point

At least MinPts points within ε-neighborhood

13. Neural Networks & Deep Learning

Neuron

z=wᵀx+b
a=f(z)

Layer equation

aˡ=f(Wˡaˡ⁻¹+bˡ)

Sigmoid

σ(z)=1/(1+e⁻ᶻ)

Tanh

tanh(z)=(eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ)

ReLU

ReLU(x)=max(0,x)

Leaky ReLU

f(x)=max(αx,x)

Softmax

softmax(z)ᵢ=eᶻⁱ/Σⱼeᶻʲ

Binary cross-entropy

L=−[ylogŷ+(1−y)log(1−ŷ)]

Mean squared error

MSE=(1/n)Σ(y−ŷ)²

Backpropagation

∂L/∂W = chain rule through network layers

Weight update

W←W−η∂L/∂W

L2 regularization

L_reg=L+λΣw²

L1 regularization

L_reg=L+λΣ|w|

Dropout keep probability

At training: randomly retain units with probability p
Implementation uses an appropriate scaling convention, often inverted dropout.

14. Optimization Algorithms

Gradient descent

θₜ₊₁=θₜ−ηgₜ

Momentum

vₜ=βvₜ₋₁+gₜ
θₜ₊₁=θₜ−ηvₜ

RMSProp

sₜ=βsₜ₋₁+(1−β)gₜ²
θ←θ−ηgₜ/(√sₜ+ε)

Adam

mₜ=β₁mₜ₋₁+(1−β₁)gₜ
vₜ=β₂vₜ₋₁+(1−β₂)gₜ²

Adam bias correction

m̂ₜ=mₜ/(1−β₁ᵗ)
v̂ₜ=vₜ/(1−β₂ᵗ)

Adam parameter update

θₜ₊₁=θₜ−η m̂ₜ/(√v̂ₜ+ε)

Learning-rate decay

ηₜ=η₀/(1+kt)
One common decay schedule; many schedules exist.

15. Information Theory & Feature Selection

Entropy

H(X)=−ΣₓP(x)log₂P(x)

Binary entropy

H(p)=−p log₂p−(1−p)log₂(1−p)

Joint entropy

H(X,Y)=−Σₓ,ᵧP(x,y)log P(x,y)

Conditional entropy

H(Y|X)=H(X,Y)−H(X)

Mutual information

I(X;Y)=H(X)+H(Y)−H(X,Y)

KL divergence

D_KL(P||Q)=ΣP(x)log[P(x)/Q(x)]

Information gain

IG=H(parent)−Σₖ(nₖ/n)H(childₖ)

Gini impurity

Gini=1−Σₖpₖ²

Cross-entropy

H(P,Q)=−ΣₓP(x)log Q(x)

AIC

AIC=2k−2ln(L̂)

BIC

BIC=k ln(n)−2ln(L̂)

Log-likelihood

ℓ(θ)=Σᵢlog p(xᵢ|θ)

Maximum likelihood

θ̂_MLE=argmax_θ L(θ)

MAP estimation

θ̂_MAP=argmax_θ P(θ|D)

MAP proportional form

P(θ|D)∝P(D|θ)P(θ)
