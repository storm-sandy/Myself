🔗 How the Agile flow connects

1 · Define Epics

Create large outcomes or initiatives. Epics group related stories and show their delivery progress.

2 · Build the Product Backlog

Create user stories or tasks and connect each to an epic. Add priority, story points, assignee and acceptance criteria. Order the backlog using priority.

3 · Plan a Sprint

Create a sprint with a goal and dates. Add stories from the product backlog to the sprint. Planned points and capacity are visible in sprint planning.

4 · Execute on the Kanban board

Move sprint stories through To Do → In Progress → In Review → Done (or Blocked). Drag cards between columns or change status from the card. All views update together.

5 · Daily Scrum

Record yesterday's progress, today's plan and blockers for each team member. Scrum notes attach to a sprint.

6 · Review, retrospective and reports

Review completed stories, remaining work, sprint completion and epic progress. Close a sprint to archive its outcome; unfinished stories return to the product backlog.
This is a local Agile planning workspace, not a multi-user server. It does not synchronize changes between devices or provide live collaboration. For team-wide Scrum, connect it to a shared backend or project platform.
