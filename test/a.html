🔗 Direct WebRTC Connection

Connect two devices by exchanging an offer and answer. Send the generated codes using a separate method, such as a messaging app or a QR code.

Both users must exchange connection information. A room code alone does not establish a WebRTC connection. This demo has no signaling server.

Connection Instructions

  1. Device A selects Create Offer.
  2. Device A sends its generated code to device B.
  3. Device B pastes that code and selects Create Answer.
  4. Device B sends its answer code to device A.
  5. Device A pastes the answer and selects Apply Remote Code.
  6. Wait for the connection to become connected.

If you receive an offer, use Create Answer. If you receive an answer to your offer, use Apply Remote Code. Both devices need a working network.

🔒 Privacy and Limitations

  • Chat history is stored in this browser's IndexedDB.
  • WebRTC messages travel directly between connected devices.
  • Room invitations do not provide authentication or encryption keys for a room.
  • WebRTC encrypts its connection, but this demo does not add application-level end-to-end identity verification.
  • Offline messages are not delivered automatically.
  • There is no central account or globally synchronized room list.
  • For a larger mesh, bandwidth and device limitations can be significant.
