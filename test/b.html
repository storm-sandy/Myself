Connection tips

1. Create an offer on Device A.
2. Copy it to Device B.
3. Apply the offer on Device B and create an answer.
4. Copy the answer back to Device A and apply it.
5. Wait for the DataChannel to open.

If the connection fails, your networks may require a TURN relay.

⚙️ Settings

TURN requires an actual server and valid credentials. Avoid embedding permanent TURN secrets in public HTML.

🔐 Security

WebRTC encrypts transport traffic, but this demo does not verify user identities. IndexedDB is not an encrypted vault. Do not use this prototype for confidential or emergency communication.
