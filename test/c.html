Connection Steps

  1. User A creates an offer.
  2. User A shares the offer text with User B.
  3. User B pastes it and selects Apply Remote Offer.
  4. User B creates an answer and sends it to User A.
  5. User A pastes the answer and selects Apply Remote Answer.

Help and Limitations

  • Designed for one-to-one WebRTC calling.
  • Camera and microphone access normally requires HTTPS or localhost.
  • Both users must exchange connection information.
  • Some networks require a TURN server.
  • This demonstration does not verify remote user identity.
  • Calls are not recorded or saved.
