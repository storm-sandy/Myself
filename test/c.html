About this demo

This demo stores profiles, contacts, conversations, messages, groups and settings in IndexedDB. WebRTC transports data peer-to-peer when a connection is established.

  • No account server or central message database.
  • Display names and peer IDs are not verified identities.
  • Local backups are unencrypted JSON unless you encrypt the exported file separately.
  • Clearing browser storage or losing a device can destroy its local copy.
  • Browser background limits mean it is not a WhatsApp replacement.

Recommended: test with two tabs/devices on separate networks. For multi-member groups, pair each participant individually; the demo broadcasts to connected peers.
