🔗 Quick Connect

To start a connection, create an offer on one device, then import that offer on the other device. Finally, exchange the answer.

🛡️ Connection reality

Direct WebRTC needs signaling information exchanged between devices. It does not guarantee that messages reach offline users. This app saves messages locally and sends them to connected peers.

🪪 My Member Identity

Your ID is generated once and stored in this browser's IndexedDB. Clearing browser data may remove it. It is an identifier, not a verified account or proof of identity.

My QR Code

This QR contains your member identity only. It does not create a WebRTC connection by itself.

📡 Exchange Connection Data

Copy the offer to the other device. The other device imports it and creates an answer. Copy that answer back to the first device.

⚙️ Connection health

The app monitors WebRTC connection state and channel state. Reconnect by creating a fresh offer if a connection is lost. Existing connections cannot always recover automatically.

🏠 Rooms

Room membership is managed locally. For group conversations, each connected member must have a direct peer connection to your device and use the same room ID.

👥 Selected Room Members

Select a room to see members.

A member appearing in a room does not necessarily mean they are currently online.

💬 Chat

Messages are saved locally. Sending only works for peers with an open WebRTC data channel. Large files may exceed browser memory or channel limits.

🗄️ Data Management

Export a JSON backup of local identity, rooms, contacts, and messages. Protect backups because they may contain private conversations.

Storage statistics

Deleting messages cannot be undone. This does not delete other users' copies.

⚙️ Settings

Privacy and security

Messages are stored in this browser's IndexedDB. WebRTC encrypts data in transit, but this prototype does not implement end-to-end identity verification, account recovery, or encrypted backups. Only connect to people you trust.
