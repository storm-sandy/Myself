📦 Import, Export & Backup

Export all catalogue entries, the current filtered results, or only your added entries. JSON backup is best for moving custom places between devices. Import can merge entries or replace your locally added entries; the built-in catalogue is protected.

Supported export/import formats: JSON, CSV, TSV, pipe-separated TXT, XML, HTML table, Markdown table, SQL INSERT statements and JSONL. For Excel, export CSV or TSV and open it in Excel/LibreOffice. PDF/XLSX are not native export formats in this no-library single HTML version; use the HTML export and your browser’s Print → Save as PDF if needed.
