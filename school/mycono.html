Storage Information

Contact data is stored in this browser on this device. It is not automatically synchronized to another device. Browser data can be lost if site storage is cleared. Export backups regularly.

CSV, JSON and vCard features work locally. SQLite import/export uses SQL.js and needs its library and WASM file to load successfully. Internet access is required for the default CDN libraries.
