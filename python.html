Q1Python Automation

What is Python automation?

Using Python programs to perform repetitive tasks automatically, such as file processing, API calls, database operations, validation, reporting, and scheduled jobs.
Q2Python Automation

Why is Python popular for automation?

It has simple syntax and a large ecosystem. Common libraries include pathlib, os, shutil, subprocess, requests, pandas, openpyxl, pytest, logging, and database drivers.
Q3Python Automation

What is the difference between a script and an automation framework?

A script usually solves one task. A framework provides reusable structure, configuration, logging, error handling, testing, reporting, and scheduling for multiple automated tasks.
Q4Python Automation

How do you handle exceptions in automation?

Use try/except around expected failures, log useful context, clean up resources with finally or context managers, and re-raise or return a controlled failure status when appropriate.
Q5Python Automation

How do you create reliable file automation?

Use pathlib, validate input files, avoid hard-coded paths, use atomic/temporary output where possible, handle encoding explicitly, log every important operation, and make reruns safe.
Q6Python Automation

How do you automate Excel files in Python?

Use openpyxl for .xlsx workbook manipulation. For tabular analysis, pandas can read and write Excel files, while openpyxl is useful for workbook-level formatting and formulas.
Q7Python Automation

How do you automate CSV processing?

Use csv for lightweight row processing or pandas for data transformations. Validate headers, data types, missing values, duplicates, and output row counts.
Q8Python Automation

How do you automate an API?

Use requests or an HTTP client, set timeouts, authenticate securely, validate status codes and response schemas, handle pagination/rate limits, and log request context without secrets.
Q9Python Automation

What is idempotency in automation?

An operation is idempotent when running it multiple times produces the same intended final state. It is important for retries and scheduled jobs.
Q10Python Automation

How do you schedule a Python automation?

Common options include cron on Linux, Windows Task Scheduler, Airflow, enterprise schedulers, CI/CD pipelines, and cloud schedulers.
Q11Python Automation

What is logging?

Logging records application events, warnings, errors, and operational context. Python's logging module supports levels, handlers, formatters, and log files.
Q12Python Automation

Why use configuration files?

Configuration separates environment-specific values such as paths, database names, URLs, and thresholds from application code. YAML, JSON, TOML, or environment variables are common choices.
Q13Python Automation

How do you manage passwords and API keys?

Do not hard-code secrets. Use environment variables, secret managers, or protected configuration mechanisms and restrict access.
Q14Python Automation

How do you run another program from Python?

Use subprocess.run() for controlled execution and inspect the return code, stdout, stderr, and timeout.
Q15Python Automation

How do you make automation testable?

Split logic into small functions/classes, inject dependencies, avoid global state, use pytest/unittest, and mock external APIs/files/databases where appropriate.
Q16Python Automation

What is retry with backoff?

A failed transient operation is retried after increasing delays, often with jitter. It reduces pressure on unstable services and helps recover from temporary failures.
Q17Python Automation

How do you monitor an automation job?

Record structured logs, execution duration, input/output counts, status, exceptions, and alerts. For production systems, metrics and dashboards can be added.
Q18Python Automation

How do you process large files efficiently?

Avoid loading everything into memory. Stream rows, process chunks, use generators, and use pandas chunksize or Spark when data becomes too large for a single machine.
Q19Python Automation

How do you prevent duplicate processing?

Use unique business keys, checkpoints, processed-file tables, transaction boundaries, idempotent writes, or watermark/state tracking.
Q20Python Automation

What is multiprocessing vs multithreading?

Threads are useful for I/O-bound work because they can overlap waiting. Processes provide separate Python interpreters and are generally better for CPU-bound Python workloads.
Q21Apache Spark / PySpark

What is Apache Spark?

Spark is a distributed data-processing engine designed for large-scale batch and streaming workloads. It provides APIs for Python, Scala, Java, and SQL.
Q22Apache Spark / PySpark

What is PySpark?

PySpark is Spark's Python API. It lets Python applications create Spark jobs and use DataFrames, SQL, RDDs, streaming, and machine-learning capabilities.
Q23Apache Spark / PySpark

Explain Spark's driver and executors.

The driver coordinates the application and creates the execution plan. Executors run tasks on worker nodes and provide computation and storage for the application.
Q24Apache Spark / PySpark

What is a Spark cluster?

A set of machines or compute resources used to execute Spark applications. A cluster manager allocates resources to Spark applications.
Q25Apache Spark / PySpark

What is SparkSession?

SparkSession is the main entry point for DataFrame and Spark SQL functionality in modern PySpark.
Q26Apache Spark / PySpark

What is an RDD?

RDD is Spark's fault-tolerant distributed collection abstraction. It is lower-level than DataFrames and gives more control, but DataFrames are usually preferred for structured data.
Q27Apache Spark / PySpark

RDD vs DataFrame?

RDDs expose lower-level distributed objects and transformations. DataFrames provide named columns, schema information, SQL support, and optimizer benefits, usually making them preferable for structured workloads.
Q28Apache Spark / PySpark

What is lazy evaluation?

Spark transformations generally do not execute immediately. Spark builds a logical plan and executes it when an action requires a result.
Q29Apache Spark / PySpark

What is a transformation?

A transformation creates a new dataset or DataFrame from an existing one, such as select, filter, withColumn, join, or groupBy.
Q30Apache Spark / PySpark

What is an action?

An action triggers execution and returns or writes a result, such as count, collect, show, first, or write.
Q31Apache Spark / PySpark

What is a DAG?

A Directed Acyclic Graph represents the stages and dependencies of Spark computation. Spark uses it to plan execution.
Q32Apache Spark / PySpark

What is a stage?

A stage is a set of tasks that can execute without a shuffle boundary. Shuffle operations often divide a job into multiple stages.
Q33Apache Spark / PySpark

What is a task?

A task is a unit of work sent to an executor, commonly corresponding to processing one partition.
Q34Apache Spark / PySpark

What is a partition?

A partition is a chunk of distributed data processed by one task at a time.
Q35Apache Spark / PySpark

What is shuffle?

Shuffle redistributes data across executors, commonly for joins, groupBy, distinct, and aggregations. It is expensive because it involves network and disk I/O.
Q36Apache Spark / PySpark

What is caching?

Caching keeps a computed dataset in memory or another storage level so repeated downstream actions can reuse it instead of recomputing it.
Q37Apache Spark / PySpark

cache() vs persist()?

cache() uses Spark's default storage level for the API, while persist() lets you select a storage level.
Q38Apache Spark / PySpark

What is broadcast join?

A small table can be broadcast to executors so Spark can join it without shuffling the large table in the usual way.
Q39Apache Spark / PySpark

What causes data skew?

Skew occurs when a few keys contain disproportionately large amounts of data, causing some partitions/tasks to take much longer.
Q40Apache Spark / PySpark

How can you handle skew?

Use techniques such as salting hot keys, broadcasting small tables, repartitioning appropriately, filtering early, or using Spark features/configurations designed for skewed joins.
Q41Apache Spark / PySpark

What is partition pruning?

When filters restrict partitioned data, Spark can avoid reading irrelevant partitions, reducing I/O.
Q42Apache Spark / PySpark

What is predicate pushdown?

Filters can be pushed closer to the data source so unnecessary rows are not read or processed, when the source supports it.
Q43Apache Spark / PySpark

What is Catalyst optimizer?

Catalyst is Spark SQL's query optimizer. It transforms logical plans into optimized plans before execution.
Q44Apache Spark / PySpark

What is Tungsten?

Tungsten refers to Spark execution improvements focused on efficient memory management, binary processing, and CPU utilization.
Q45Apache Spark / PySpark

What is a narrow transformation?

A transformation where each output partition depends on a small number of input partitions without requiring a full data shuffle, such as map or filter.
Q46Apache Spark / PySpark

What is a wide transformation?

A transformation that can require data movement between partitions, such as groupByKey or many joins and aggregations.
Q47Apache Spark / PySpark

repartition vs coalesce?

repartition can increase or decrease partitions and normally causes a shuffle. coalesce is commonly used to reduce partitions with less data movement.
Q48Apache Spark / PySpark

Why avoid collect() on large data?

collect() transfers all rows to the driver and can exhaust driver memory. Use show, take, limit, aggregations, or write results instead.
Q49Apache Spark / PySpark

How do you read a CSV in PySpark?

Use spark.read.option('header', True).option('inferSchema', True).csv(path), preferably with an explicit schema for production pipelines.
Q50Apache Spark / PySpark

How do you define a schema?

Use StructType with StructField definitions, for example StructType([StructField('id', IntegerType(), True), StructField('name', StringType(), True)]).
Q51Spark DataFrame

What is a Spark DataFrame?

A distributed collection of structured data organized into named columns. Spark can optimize DataFrame operations using its SQL engine.
Q52Spark DataFrame

How do you create a DataFrame?

Use spark.createDataFrame() from local collections, pandas DataFrames, RDDs, or read data through spark.read.
Q53Spark DataFrame

How do you select columns?

Use df.select('id', 'name') or column expressions such as df.select(F.col('id'), F.col('name')).
Q54Spark DataFrame

How do you filter rows?

Use df.filter(F.col('salary') > 50000) or df.where(...).
Q55Spark DataFrame

How do you add a column?

Use withColumn(), for example df.withColumn('bonus', F.col('salary') * 0.1).
Q56Spark DataFrame

How do you rename a column?

Use withColumnRenamed('old_name', 'new_name') or select with an alias.
Q57Spark DataFrame

How do you drop a column?

Use df.drop('column_name').
Q58Spark DataFrame

How do you remove duplicates?

Use dropDuplicates(), optionally passing a subset of business-key columns.
Q59Spark DataFrame

How do you handle nulls?

Use dropna(), fillna(), or explicit when/otherwise expressions depending on business rules.
Q60Spark DataFrame

How do you group data?

Use df.groupBy('department').agg(F.sum('salary'), F.avg('salary')).
Q61Spark DataFrame

How do you sort a DataFrame?

Use orderBy() or sort(). For descending order use F.col('salary').desc().
Q62Spark DataFrame

How do you join DataFrames?

Use df1.join(df2, on='id', how='inner') or a compound condition.
Q63Spark DataFrame

What are common join types?

inner, left, right, full, left_semi, and left_anti are commonly used.
Q64Spark DataFrame

What is left_semi join?

It returns rows from the left DataFrame that have a matching key in the right DataFrame, without bringing right-side columns.
Q65Spark DataFrame

What is left_anti join?

It returns rows from the left DataFrame with no matching key in the right DataFrame.
Q66Spark DataFrame

What is a window function?

A window function computes values across related rows while retaining row-level detail. Examples include row_number, rank, lag, lead, and running sums.

Q68Spark DataFrame

What is explode()?

explode() turns each element of an array or map into a separate output row.
Q69Spark DataFrame

What is pivot?

pivot reshapes grouped data by turning distinct values into columns, often for reporting.
Q70Spark DataFrame

How do you parse dates?

Use functions such as to_date and to_timestamp with an explicit format when necessary.
Q71Spark DataFrame

What is cast?

cast changes a column's data type, such as converting a string to integer or timestamp.
Q72Spark DataFrame

How do you use conditional logic?

Use when(...).otherwise(...) from pyspark.sql.functions.
Q73Spark DataFrame

What is unionByName?

It combines DataFrames by matching columns by name. allowMissingColumns=True can be useful when schemas evolve.
Q74Spark DataFrame

How do you inspect a DataFrame?

Use printSchema(), show(), columns, dtypes, describe(), and explain().
Q75Spark DataFrame

What does explain() show?

It displays query plans, including logical and physical execution plans, useful for diagnosing performance.
Q76Spark DataFrame

How do you write Parquet?

Use df.write.mode('overwrite').parquet(path). Parquet is columnar and commonly used for analytics.
Q77Spark DataFrame

Parquet vs CSV?

Parquet is columnar, typed, compressed, and usually much more efficient for analytical Spark workloads. CSV is text-based and easier to exchange but less efficient.
Q78Spark DataFrame

What is partitionBy when writing?

Data can be physically organized into directory partitions by selected columns, allowing partition pruning during reads.
Q79Spark DataFrame

What is a UDF?

A User Defined Function lets custom Python logic be applied to Spark columns, but Python UDFs can add serialization overhead. Built-in Spark functions are generally preferred.
Q80Spark DataFrame

How do you optimize a DataFrame job?

Select only needed columns, filter early, use efficient file formats, avoid unnecessary shuffles, choose sensible partitions, broadcast genuinely small tables, and inspect the physical plan.
Q81Scenario & Coding

Scenario: A daily CSV has 10 million rows. What pipeline would you build?

Land the file, validate schema and file metadata, read with an explicit schema, filter/project early, transform using built-in Spark functions, validate counts and keys, write an efficient format such as Parquet, and record audit status.
Q82Scenario & Coding

Scenario: A Spark join is very slow. What do you check?

Check table sizes, join keys, skew, number of partitions, shuffle read/write, broadcast possibility, filters, file layout, and the physical plan from explain().
Q83Scenario & Coding

Scenario: One customer ID has millions of rows. How do you address skew?

Confirm the hot key from distribution metrics, then consider salting, broadcasting the smaller side, splitting hot-key processing, or enabling appropriate skew-join optimizations.
Q84Scenario & Coding

Scenario: Your automation fails halfway through. How do you make it restartable?

Persist checkpoints/status, make writes idempotent, process inputs in independently retryable units, use temporary output followed by an atomic completion step, and record audit metadata.
Q85Scenario & Coding

Scenario: Duplicate records arrive every day. What do you do?

Define a business key, deduplicate with deterministic ordering, validate duplicate counts, and make downstream writes idempotent.
Q86Scenario & Coding

Scenario: Data quality checks fail. Should the pipeline always stop?

It depends on severity. Critical schema/key violations should normally fail the job; noncritical anomalies can be quarantined and alerted while allowing safe processing.

Q100Scenario & Coding

Interview: Why prefer built-in Spark functions over Python UDFs?

Built-in functions are understood by Spark's optimizer and can execute efficiently inside Spark's engine. Python UDFs may introduce serialization and execution overhead.
