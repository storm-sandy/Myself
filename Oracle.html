Q1Oracle SQL Fundamentals

What is Oracle Database?

Oracle Database is a relational database management system that supports SQL, PL/SQL, transactions, indexing, partitioning, security, high availability, and large-scale enterprise workloads.
Q2Oracle SQL Fundamentals

What is SQL?

SQL is the language used to define, query, manipulate, and control relational data. Common areas are DDL, DML, DQL, DCL, and transaction control.
Q3Oracle SQL Fundamentals

What is a primary key?

A primary key uniquely identifies each row. It cannot contain NULL values and a table has one primary-key constraint, which may contain multiple columns.
Q4Oracle SQL Fundamentals

What is a foreign key?

A foreign key enforces a relationship between a child table and a parent key. It prevents invalid references unless the constraint is configured to allow the relevant behavior.
Q5Oracle SQL Fundamentals

Primary key vs unique key?

A primary key uniquely identifies rows and does not allow NULL. A unique constraint also enforces uniqueness, while Oracle's handling of NULL values differs from a primary key.
Q6Oracle SQL Fundamentals

What is normalization?

Normalization organizes data to reduce unnecessary redundancy and update anomalies. Common normal forms include 1NF, 2NF, and 3NF.
Q7Oracle SQL Fundamentals

What is denormalization?

Denormalization intentionally introduces controlled redundancy to improve read performance or simplify reporting, with a trade-off in storage and maintenance.
Q8Oracle SQL Fundamentals

DELETE vs TRUNCATE vs DROP?

DELETE removes selected rows and is DML. TRUNCATE removes all rows with DDL semantics and is generally faster. DROP removes the object itself.
Q9Oracle SQL Fundamentals

WHERE vs HAVING?

WHERE filters rows before grouping. HAVING filters groups after GROUP BY and aggregation.
Q10Oracle SQL Fundamentals

UNION vs UNION ALL?

UNION combines result sets and removes duplicates. UNION ALL combines them without duplicate elimination and is usually faster.
Q11Oracle SQL Fundamentals

INNER JOIN vs OUTER JOIN?

INNER JOIN returns matching rows. LEFT, RIGHT, and FULL OUTER JOINs preserve rows from one or both sides even when no match exists.
Q12Oracle SQL Fundamentals

What is a self join?

A table is joined to itself using aliases, often for hierarchical relationships such as employee-manager data.
Q13Oracle SQL Fundamentals

What is a correlated subquery?

A subquery that references columns from the outer query and is logically evaluated in relation to each outer row.
Q14Oracle SQL Fundamentals

What is a CTE?

A Common Table Expression uses WITH to define a named query block that can make complex SQL easier to read and can support recursive/hierarchical patterns.
Q15Oracle SQL Fundamentals

What is a view?

A view is a stored query presented as a virtual table. It can simplify access, encapsulate logic, and restrict exposed columns/rows.
Q16Oracle SQL Fundamentals

What is a materialized view?

A materialized view stores query results physically and can be refreshed. It is useful for expensive reporting and aggregation workloads.
Q17Oracle SQL Fundamentals

What is a sequence?

A sequence generates numeric values independently of table rows, commonly used for surrogate keys.
Q18Oracle SQL Fundamentals

What is a synonym?

A synonym provides an alternative name for a database object and can simplify references or hide schema names.
Q19Oracle SQL Fundamentals

What is an index?

An index is a data structure that can speed up searches, joins, and ordering, but adds storage and DML maintenance overhead.
Q20Oracle SQL Fundamentals

B-tree vs bitmap index?

B-tree indexes are general-purpose and commonly suited to OLTP columns with varied values. Bitmap indexes can be effective for low-cardinality analytical workloads but may be unsuitable for high-concurrency OLTP updates.
Q21Advanced SQL

What is an analytic function?

An analytic/window function calculates a value over a related set of rows while retaining individual rows. Examples include ROW_NUMBER, RANK, LAG, LEAD, and SUM OVER.
Q22Advanced SQL

ROW_NUMBER vs RANK vs DENSE_RANK?

ROW_NUMBER assigns unique sequential numbers. RANK gives equal values the same rank with gaps after ties. DENSE_RANK gives equal values the same rank without gaps.
Q23Advanced SQL

How do you find the second-highest salary?

A robust approach is DENSE_RANK over salary descending and filter rank = 2. Another approach is a distinct ordered subquery with FETCH/OFFSET depending on the requirement.
Q24Advanced SQL

How do you get the top 3 salaries per department?

Use DENSE_RANK or ROW_NUMBER partitioned by department and ordered by salary descending, then filter the ranking column to <= 3.
Q25Advanced SQL

What is MERGE?

MERGE can conditionally INSERT, UPDATE, and in supported designs DELETE based on whether source rows match target rows. It is commonly used for upsert-style processing.
Q26Advanced SQL

What is a hierarchical query?

Oracle supports hierarchical queries using CONNECT BY and PRIOR. Recursive subquery factoring is another approach for hierarchy traversal.
Q27Advanced SQL

What is CONNECT BY?

CONNECT BY defines parent-child relationships for hierarchical queries, commonly with START WITH to identify root rows.
Q28Advanced SQL

What is PIVOT?

PIVOT transforms row values into columns and applies aggregation, useful for reporting.
Q29Advanced SQL

What is UNPIVOT?

UNPIVOT converts columns into rows, reversing a common pivot-style transformation.
Q30Advanced SQL

What is MATCH_RECOGNIZE?

MATCH_RECOGNIZE is an advanced SQL feature for row-pattern matching, useful for detecting sequences and events in ordered data.
Q31Advanced SQL

What is a scalar subquery?

A scalar subquery returns at most one value for each outer evaluation context and can be used where an expression is expected.
Q32Advanced SQL

EXISTS vs IN?

EXISTS checks whether a matching row exists. IN compares values against a set. The optimizer may transform them, but NULL semantics and data distribution can affect results and performance.
Q33Advanced SQL

What is a function-based index?

It indexes the result of an expression, such as UPPER(email), enabling efficient access when the query uses the same expression.
Q34Advanced SQL

What is partitioning?

Partitioning divides a large table or index into manageable pieces while presenting it as one logical object. Common methods include range, list, hash, and composite partitioning.
Q35Advanced SQL

What is partition pruning?

The optimizer can eliminate partitions that cannot satisfy query predicates, reducing I/O.
Q36Advanced SQL

What is an execution plan?

It describes how Oracle intends to execute SQL, including access paths, joins, cardinality estimates, and operations. EXPLAIN PLAN and DBMS_XPLAN are commonly used for inspection.
Q37Advanced SQL

What is the cost-based optimizer?

Oracle's optimizer chooses an execution plan using statistics, SQL structure, available indexes, system information, and cost estimates.
Q38Advanced SQL

What are bind variables?

Bind variables separate SQL text from runtime values, improving cursor sharing and reducing parsing overhead while helping protect against SQL injection when used correctly.
Q39Advanced SQL

What is a deadlock?

A deadlock occurs when sessions hold resources and wait for resources held by each other. Oracle detects deadlocks and rolls back a statement involved in the cycle.
Q40Advanced SQL

What is a transaction?

A transaction is a logical unit of work governed by COMMIT, ROLLBACK, and savepoint semantics.
Q41PL/SQL

What is PL/SQL?

PL/SQL is Oracle's procedural extension to SQL. It supports variables, conditions, loops, exception handling, cursors, procedures, functions, packages, and triggers.
Q42PL/SQL

What is a PL/SQL block?

A block can contain an optional DECLARE section, a required executable BEGIN...END section, and an optional EXCEPTION section.
Q43PL/SQL

Procedure vs function?

A procedure performs an action and can have OUT parameters. A function returns a value and can often be used in SQL subject to Oracle's rules and restrictions.
Q44PL/SQL

What is a package?

A package groups related procedures, functions, variables, types, cursors, and exceptions. It has a specification and usually a body.
Q45PL/SQL

Package specification vs body?

The specification exposes the public interface. The body contains implementation details and private declarations.
Q46PL/SQL

What is %TYPE?

%TYPE declares a variable using the datatype of another variable or table column, helping keep declarations aligned with database definitions.
Q47PL/SQL

What is %ROWTYPE?

%ROWTYPE declares a record with fields corresponding to an entire table row or cursor row structure.
Q48PL/SQL

What is an implicit cursor?

Oracle automatically manages an implicit cursor for SQL statements such as INSERT, UPDATE, DELETE, and SELECT INTO.
Q49PL/SQL

What is an explicit cursor?

An explicit cursor is declared and controlled by the programmer, commonly using OPEN, FETCH, and CLOSE or a cursor FOR loop.
Q50PL/SQL

What is cursor FOR loop?

A cursor FOR loop automatically opens the cursor, fetches rows into a record, and closes the cursor, reducing boilerplate.
Q51PL/SQL

What is BULK COLLECT?

BULK COLLECT fetches multiple rows into collections in one operation, reducing context switches between PL/SQL and SQL.
Q52PL/SQL

What is FORALL?

FORALL sends DML for collections in batches and can greatly reduce context switching compared with row-by-row DML.
Q53PL/SQL

What is SAVE EXCEPTIONS?

FORALL SAVE EXCEPTIONS allows processing to continue for other collection elements while capturing individual DML errors in SQL%BULK_EXCEPTIONS.
Q54PL/SQL

What is exception handling?

PL/SQL uses EXCEPTION blocks to handle predefined, user-defined, and OTHERS exceptions. Good handlers log context and handle or propagate errors deliberately.
Q55PL/SQL

RAISE vs RAISE_APPLICATION_ERROR?

RAISE raises an existing exception or the currently handled exception. RAISE_APPLICATION_ERROR raises a custom application error with a user-defined error number in the supported range.
Q56PL/SQL

What is dynamic SQL?

Dynamic SQL builds or executes SQL at runtime. EXECUTE IMMEDIATE is commonly used; bind variables should be used for runtime values.
Q57PL/SQL

What is a trigger?

A trigger is stored PL/SQL that fires automatically for specified database events, such as DML or certain DDL/system events.
Q58PL/SQL

BEFORE vs AFTER trigger?

A BEFORE trigger runs before the triggering event completes and can be used for validation or derived values. AFTER triggers run after the event.
Q59PL/SQL

Row-level vs statement-level trigger?

A row-level trigger fires once per affected row and uses FOR EACH ROW. A statement-level trigger fires once per triggering statement.
Q60PL/SQL

What is a compound trigger?

A compound trigger combines multiple timing sections and can maintain shared state across the statement, useful for certain complex DML scenarios.
Q61Advanced PL/SQL & Performance

What is mutating table error?

ORA-04091 can occur when a row-level trigger tries to query or modify the table currently being changed. Solutions include compound triggers or redesigning the logic.
Q62Advanced PL/SQL & Performance

What is an autonomous transaction?

A routine or block declared PRAGMA AUTONOMOUS_TRANSACTION executes independently and can commit or roll back without committing the caller's transaction. It should be used carefully.
Q63Advanced PL/SQL & Performance

What is NOCOPY?

NOCOPY is a compiler hint for OUT/IN OUT parameters that can reduce copying overhead. It can change parameter behavior on exceptions, so it requires careful use.
Q64Advanced PL/SQL & Performance

What is native dynamic SQL?

Native dynamic SQL uses EXECUTE IMMEDIATE or OPEN FOR to execute runtime-generated SQL/PLSQL and is generally simpler than older DBMS_SQL for many use cases.
Q65Advanced PL/SQL & Performance

DBMS_SQL vs EXECUTE IMMEDIATE?

EXECUTE IMMEDIATE is convenient for many dynamic statements. DBMS_SQL offers lower-level control, useful for highly dynamic SQL where columns or metadata are not known at compile time.
Q66Advanced PL/SQL & Performance

What is result caching?

PL/SQL function result cache can reuse results for repeated calls when appropriate. It should be used only when dependencies and invalidation behavior make caching safe.
Q67Advanced PL/SQL & Performance

What is DBMS_SCHEDULER?

DBMS_SCHEDULER provides database job scheduling capabilities, including jobs, programs, schedules, chains, and job monitoring.
Q68Advanced PL/SQL & Performance

How do you tune slow PL/SQL?

Find the slow SQL first, inspect execution plans and statistics, reduce row-by-row processing, use set-based SQL, BULK COLLECT/FORALL where appropriate, and measure before/after.
Q69Advanced PL/SQL & Performance

Why is row-by-row processing slow?

Repeated SQL-to-PL/SQL context switches and individual DML operations can be expensive. Set-based SQL or bulk processing usually performs better.
Q70Advanced PL/SQL & Performance

What is context switching?

It is the transfer between the SQL engine and PL/SQL engine. Excessive switching can hurt performance, especially inside loops.
Q71Advanced PL/SQL & Performance

What is SQL%ROWCOUNT?

It returns the number of rows affected or returned by the most recent SQL statement in the current implicit cursor context.
Q72Advanced PL/SQL & Performance

What are SQL%FOUND and SQL%NOTFOUND?

They indicate whether the most recent implicit cursor SQL operation affected or fetched a row, according to the statement context.
Q73Advanced PL/SQL & Performance

What is a REF CURSOR?

A REF CURSOR is a cursor variable that can point to a query result set. SYS_REFCURSOR is a commonly used weak REF CURSOR type.
Q74Advanced PL/SQL & Performance

Strong vs weak REF CURSOR?

A strong REF CURSOR has a fixed return row type. A weak REF CURSOR does not specify the row structure at declaration time and is more flexible.
Q75Advanced PL/SQL & Performance

What is a collection in PL/SQL?

Collections are PL/SQL data structures such as associative arrays, nested tables, and varrays used to hold multiple values.
Q76Advanced PL/SQL & Performance

Associative array vs nested table vs varray?

Associative arrays are key-value PL/SQL structures. Nested tables are unbounded collections that can be stored in the database. Varrays have an upper bound and preserve order.
Q77Advanced PL/SQL & Performance

What is PRAGMA EXCEPTION_INIT?

It associates a named PL/SQL exception with a specific Oracle error number, allowing clearer exception handling.
Q78Advanced PL/SQL & Performance

How should errors be logged?

Log meaningful context such as module, key identifiers, timestamp, SQLCODE, SQLERRM, and a stack/backtrace where appropriate, without exposing secrets.
Q79Advanced PL/SQL & Performance

Why avoid WHEN OTHERS THEN NULL?

It silently suppresses errors and makes failures difficult to detect and troubleshoot. Handle expected errors explicitly or log and re-raise unexpected ones.
Q80Advanced PL/SQL & Performance

What is DBMS_XPLAN?

DBMS_XPLAN displays execution plans and related information, often including actual runtime statistics when the relevant plan data is available.
Q81Oracle Architecture & DBA Concepts

SGA vs PGA?

The SGA is shared memory used by an Oracle instance. PGA is process-specific memory used for session/work areas and related operations.
Q82Oracle Architecture & DBA Concepts

What is an Oracle instance?

An instance consists of memory structures such as the SGA and background processes that manage access to the database files.
Q83Oracle Architecture & DBA Concepts

What is a database in Oracle architecture?

The database is the physical collection of files, including datafiles, control files, and online redo logs, associated with an instance.
Q84Oracle Architecture & DBA Concepts

What is a tablespace?

A tablespace is a logical storage unit composed of one or more datafiles and contains database segments.
Q85Oracle Architecture & DBA Concepts

What is a segment?

A segment is storage allocated for an object such as a table, index, or LOB.
Q86Oracle Architecture & DBA Concepts

What is a data block?

A data block is Oracle's basic unit of logical database storage and I/O.
Q87Oracle Architecture & DBA Concepts

What are redo logs?

Redo records describe changes so Oracle can recover committed changes after failures and support instance recovery.
Q88Oracle Architecture & DBA Concepts

What is undo?

Undo stores information needed for transaction rollback and consistent reads, and supports features such as flashback.
Q89Oracle Architecture & DBA Concepts

What is an SCN?

System Change Number is a logical timestamp used by Oracle to order changes and coordinate consistency and recovery.
Q90Oracle Architecture & DBA Concepts

What is read consistency?

Oracle provides consistent query results using mechanisms including undo, allowing a query to see a consistent version of data.
Q91Oracle Architecture & DBA Concepts

What is RAC?

Oracle Real Application Clusters allows multiple instances to access the same database, supporting scalability and availability.
Q92Oracle Architecture & DBA Concepts

What is Data Guard?

Oracle Data Guard provides standby database capabilities for disaster recovery, availability, and data protection.
Q93Oracle Architecture & DBA Concepts

What is RMAN?

Recovery Manager is Oracle's backup and recovery utility for database backups, restores, and recovery operations.
Q94Oracle Architecture & DBA Concepts

What is Flashback?

Flashback technologies provide ways to inspect or recover past data/database states using mechanisms such as undo, flashback logs, and archived information depending on the feature.
Q95Oracle Architecture & DBA Concepts

What is an AWR report?

Automatic Workload Repository reports provide historical performance information used to diagnose database workload and performance problems, subject to licensing and configuration.
Q96Real-Time Interview Scenarios

A query suddenly became slow after deployment. What do you do?

Compare execution plans and statistics, check bind values/data distribution, recent object changes, indexes, blocking, I/O, and plan changes. Use measured evidence rather than immediately adding indexes.
Q97Real-Time Interview Scenarios

A stored procedure takes 30 minutes for 1 million rows. How do you tune it?

Profile the procedure, identify SQL hotspots, replace row-by-row loops with set-based SQL, use bulk processing where needed, review indexes and joins, reduce unnecessary commits, and validate with execution metrics.
Q98Real-Time Interview Scenarios

A report needs the latest order for every customer. What SQL would you use?

Use ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY order_date DESC, order_id DESC) and filter row_number = 1, or another deterministic analytic approach.
Q99Real-Time Interview Scenarios

How would you detect duplicate business keys?

GROUP BY the business key and use HAVING COUNT(*) > 1. For identifying the rows, add ROW_NUMBER or DENSE_RANK over the business key.
Q100Real-Time Interview Scenarios

How would you delete duplicates but retain one row?

Assign ROW_NUMBER partitioned by the business key with deterministic ordering, then delete rows where row_number > 1. Test carefully and preserve a recovery path.
Q101Real-Time Interview Scenarios

How would you process 10 million records in PL/SQL?

Prefer a single set-based SQL statement where possible. If procedural logic is necessary, use BULK COLLECT with a LIMIT and FORALL, monitor memory, handle exceptions, and commit according to transaction requirements.
Q102Real-Time Interview Scenarios

A trigger causes ORA-04091. What is your approach?

Understand why the trigger needs the table being changed, avoid querying the mutating table from a row trigger, and consider a compound trigger or moving business logic to a controlled procedure.
Q103Real-Time Interview Scenarios

How do you safely build dynamic SQL from user input?

Never concatenate untrusted values into SQL identifiers/values without validation. Use bind variables for values and whitelist allowed identifiers/options.
Q104Real-Time Interview Scenarios

How do you troubleshoot blocking sessions?

Identify blocker and waiter sessions, inspect transaction state and SQL, determine why the transaction is open, coordinate with the application owner, and resolve the root cause rather than simply killing sessions.
Q105Real-Time Interview Scenarios

How do you design an ETL load in Oracle?

Use staging tables, validate and standardize input, load in set-based operations, maintain audit/control tables, use MERGE or appropriate DML, handle rejects, make reruns safe, and monitor row counts and timings.
Q106SQL/PLSQL Coding Questions

Write SQL to find employees earning above their department average.

Use a correlated comparison or analytic average: SELECT * FROM (SELECT e.*, AVG(salary) OVER (PARTITION BY department_id) dept_avg FROM employees e) WHERE salary > dept_avg.
Q107SQL/PLSQL Coding Questions

Write SQL for a running salary total by department.

Use SUM(salary) OVER (PARTITION BY department_id ORDER BY employee_id ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW).
Q108SQL/PLSQL Coding Questions

Write SQL to find departments with more than 5 employees.

SELECT department_id, COUNT(*) FROM employees GROUP BY department_id HAVING COUNT(*) > 5;
Q109SQL/PLSQL Coding Questions

Write a PL/SQL anonymous block to print employee count.

DECLARE l_count NUMBER; BEGIN SELECT COUNT(*) INTO l_count FROM employees; DBMS_OUTPUT.PUT_LINE('Employees='||l_count); END;
Q110SQL/PLSQL Coding Questions

Write PL/SQL to handle NO_DATA_FOUND.

BEGIN SELECT name INTO l_name FROM employees WHERE employee_id = p_id; EXCEPTION WHEN NO_DATA_FOUND THEN DBMS_OUTPUT.PUT_LINE('Employee not found'); END;
Q111SQL/PLSQL Coding Questions

Write a procedure to increase salary by percentage.

CREATE OR REPLACE PROCEDURE increase_salary(p_dept_id NUMBER,p_pct NUMBER) IS BEGIN UPDATE employees SET salary = salary * (1+p_pct/100) WHERE department_id=p_dept_id; END;
Q112SQL/PLSQL Coding Questions

Write a function returning employee count for a department.

CREATE OR REPLACE FUNCTION employee_count(p_dept_id NUMBER) RETURN NUMBER IS l_count NUMBER; BEGIN SELECT COUNT(*) INTO l_count FROM employees WHERE department_id=p_dept_id; RETURN l_count; END;
Q113SQL/PLSQL Coding Questions

Show a FORALL pattern.

DECLARE TYPE t_ids IS TABLE OF employees.employee_id%TYPE; l_ids t_ids; BEGIN SELECT employee_id BULK COLLECT INTO l_ids FROM employees WHERE department_id=10; FORALL i IN 1..l_ids.COUNT UPDATE employees SET salary=salary*1.05 WHERE employee_id=l_ids(i); END;
Q114SQL/PLSQL Coding Questions

Show a cursor FOR loop.

FOR r IN (SELECT employee_id, salary FROM employees WHERE department_id=10) LOOP DBMS_OUTPUT.PUT_LINE(r.employee_id||':'||r.salary); END LOOP;
