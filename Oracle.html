Q1Oracle SQL Fundamentals

What is Oracle Database?

Oracle Database is a relational database management system that supports SQL, PL/SQL, transactions, indexing, partitioning, security, high availability, and large-scale enterprise workloads.
Q2Oracle SQL Fundamentals

What is SQL?

SQL is the language used to define, query, manipulate, and control relational data. Common areas are DDL, DML, DQL, DCL, and transaction control.
Q3Oracle SQL Fundamentals

What is a primary key?

A primary key uniquely identifies each row. It cannot contain NULL values and a table has one primary-key constraint, which may contain multiple columns.
Q4Oracle SQL Fundamentals

What is a foreign key?

A foreign key enforces a relationship between a child table and a parent key. It prevents invalid references unless the constraint is configured to allow the relevant behavior.
Q5Oracle SQL Fundamentals

Primary key vs unique key?

A primary key uniquely identifies rows and does not allow NULL. A unique constraint also enforces uniqueness, while Oracle's handling of NULL values differs from a primary key.
Q6Oracle SQL Fundamentals

What is normalization?

Normalization organizes data to reduce unnecessary redundancy and update anomalies. Common normal forms include 1NF, 2NF, and 3NF.
Q7Oracle SQL Fundamentals

What is denormalization?

Denormalization intentionally introduces controlled redundancy to improve read performance or simplify reporting, with a trade-off in storage and maintenance.
Q8Oracle SQL Fundamentals

DELETE vs TRUNCATE vs DROP?

DELETE removes selected rows and is DML. TRUNCATE removes all rows with DDL semantics and is generally faster. DROP removes the object itself.
Q9Oracle SQL Fundamentals

WHERE vs HAVING?

WHERE filters rows before grouping. HAVING filters groups after GROUP BY and aggregation.
Q10Oracle SQL Fundamentals

UNION vs UNION ALL?

UNION combines result sets and removes duplicates. UNION ALL combines them without duplicate elimination and is usually faster.
Q11Oracle SQL Fundamentals

INNER JOIN vs OUTER JOIN?

INNER JOIN returns matching rows. LEFT, RIGHT, and FULL OUTER JOINs preserve rows from one or both sides even when no match exists.
Q12Oracle SQL Fundamentals

What is a self join?

A table is joined to itself using aliases, often for hierarchical relationships such as employee-manager data.
Q13Oracle SQL Fundamentals

What is a correlated subquery?

A subquery that references columns from the outer query and is logically evaluated in relation to each outer row.
Q14Oracle SQL Fundamentals

What is a CTE?

A Common Table Expression uses WITH to define a named query block that can make complex SQL easier to read and can support recursive/hierarchical patterns.
Q15Oracle SQL Fundamentals

What is a view?

A view is a stored query presented as a virtual table. It can simplify access, encapsulate logic, and restrict exposed columns/rows.
Q16Oracle SQL Fundamentals

What is a materialized view?

A materialized view stores query results physically and can be refreshed. It is useful for expensive reporting and aggregation workloads.
Q17Oracle SQL Fundamentals

What is a sequence?

A sequence generates numeric values independently of table rows, commonly used for surrogate keys.
Q18Oracle SQL Fundamentals

What is a synonym?

A synonym provides an alternative name for a database object and can simplify references or hide schema names.
Q19Oracle SQL Fundamentals

What is an index?

An index is a data structure that can speed up searches, joins, and ordering, but adds storage and DML maintenance overhead.
Q20Oracle SQL Fundamentals

B-tree vs bitmap index?

B-tree indexes are general-purpose and commonly suited to OLTP columns with varied values. Bitmap indexes can be effective for low-cardinality analytical workloads but may be unsuitable for high-concurrency OLTP updates.
Q21Advanced SQL

What is an analytic function?

An analytic/window function calculates a value over a related set of rows while retaining individual rows. Examples include ROW_NUMBER, RANK, LAG, LEAD, and SUM OVER.
